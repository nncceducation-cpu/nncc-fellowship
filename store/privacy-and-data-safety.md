# Privacy declarations — IMPORTANT: this app DOES collect data

The portal authenticates users through Supabase and stores profile, progress, forum
posts, etc. So you must NOT answer "Data Not Collected." Declare the following.

## Data the app collects / transmits
| Data type            | Collected | Linked to user | Purpose                    |
|----------------------|-----------|----------------|----------------------------|
| Email address        | Yes       | Yes            | Account / sign-in          |
| Name                 | Yes       | Yes            | Account / directory        |
| Course progress      | Yes       | Yes            | App functionality          |
| User content (forum) | Yes       | Yes            | App functionality          |
| Country / profession | Yes (join)| Yes            | Membership administration  |

- Not used for tracking/advertising. No Advertising ID. No data sold.
- Data is processed by Supabase (backend) on the program's behalf.

## Apple App Privacy
- Contact Info → Email, Name → "App Functionality," linked to identity, not for tracking.
- User Content → Forum posts → "App Functionality," linked, not for tracking.
- Identifiers/Usage → only if you add analytics later (currently none).

## Google Play Data safety
- Personal info: Email, Name → collected, encrypted in transit, linked to user,
  purpose "Account management / App functionality," not shared with third parties for ads.
- Messages/User content: forum posts → collected, linked, app functionality.
- Data deletion: provide the account-deletion route (email the program admin) — Google
  now expects a way for users to request deletion.

## Privacy Policy page (REQUIRED by both stores)
You must publish a privacy policy at a public URL (e.g. https://sarnatnncc.ca/privacy.html).
A starter page is provided at store/privacy.html — review it with your institution, then
add it to the repo root and link it in the app footer.
